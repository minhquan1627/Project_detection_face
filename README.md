#  AI Face Recognition System

A powerful and easy-to-use AI-based Face Recognition system built with Python and Deep Learning. This project can detect and recognize human faces in real-time using webcam, images, or videos.

---

##  Installation – Cài đặt về máy

###  Yêu cầu hệ thống

- Python 3.10
- pip
- cmake
- dlib (có thể cần Visual Studio Build Tools trên Windows)
- Webcam (nếu chạy real-time)

### 📥 Các bước cài đặt

**Clone dự án:**

```bash
git clone https://github.com/yourusername/face-recognition-ai.git
cd face-recognition-ai
```
**Cài đặt thư viện:**
```bash
pip install -r requirements.txt
```
